# Portfólio de Automações com Power Automate

Olá! Eu sou João Batista e este repositório reúne meus projetos de automação desenvolvidos com **Microsoft Power Automate**.

Meu foco é criar soluções que reduzem tarefas manuais, organizam processos e aumentam a produtividade por meio de integrações entre ferramentas como SharePoint, Outlook, Teams, Excel, Forms e outros serviços do Microsoft 365.

## Sobre este portfólio

Aqui você encontrará exemplos de automações criadas para cenários corporativos, como:

- Aprovação de solicitações
- Envio automático de e-mails e notificações
- Controle de prazos e vencimentos
- Integração entre SharePoint, Outlook, Teams e Excel
- Organização de dados e processos internos
- Redução de tarefas repetitivas

## Tecnologias utilizadas

- Microsoft Power Automate
- SharePoint
- Outlook
- Microsoft Teams
- Excel
- Microsoft Forms
- Conectores do Microsoft 365
- Condições, variáveis, loops e aprovações
- Tratamento de erros em fluxos automatizados

## Projetos

| Projeto | Descrição | Tecnologias |
|---|---|---|
| Aprovação de Solicitações | Fluxo para automatizar aprovações internas e notificar os responsáveis | Power Automate, SharePoint, Outlook |
| Alerta de Vencimento de Prazos | Automação que verifica datas próximas do vencimento e envia alertas automáticos | Power Automate, SharePoint, Teams |
| Organização de Dados | Fluxo para registrar e padronizar informações recebidas por formulário ou e-mail | Power Automate, Forms, Excel |

## Estrutura dos projetos

Cada projeto será documentado com:

- Problema resolvido
- Objetivo da automação
- Explicação do funcionamento do fluxo
- Ferramentas e conectores utilizados
- Prints ou diagramas do processo
- Resultados obtidos
- Possíveis melhorias futuras

## Objetivo profissional

Este portfólio tem como objetivo demonstrar minha experiência prática na criação de automações com Power Automate, documentação de processos e melhoria contínua de rotinas administrativas e operacionais.
